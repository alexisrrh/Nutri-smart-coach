# Funcionalidades

Este directorio documenta las funcionalidades actuales confirmadas en el codigo de NutriSmart Coach. Antes de modificar una funcionalidad, lee este indice, su documento especifico y los modulos tecnicos relacionados en `../modules/`.

## Indice

- `authentication.md`: sesion Supabase, rutas protegidas y consentimiento legal.
- `ai-food-analysis.md`: analisis IA de fotos/descripciones de comida.
- `diets.md`: generacion de planes de dieta, progreso y reescritura premium.
- `meals.md`: historial, borrado y totales de comidas analizadas.
- `checkins.md`: check-ins corporales con imagen y analisis IA.
- `progress.md`: registros de peso, resumen de progreso y gamificacion.
- `routines.md`: rutinas personalizadas, sesiones y comparticion publica.
- `premium.md`: estado Premium, Stripe y verificacion movil.
- `referrals.md`: codigos de invitacion y recompensas.
- `creators.md`: panel de creadores, solicitudes, enlaces y pagos.
- `profile-settings.md`: perfil, preferencias, tema, IA, legal y seguridad.

## Uso

- Consulta el documento de funcionalidad antes de tocar paginas, hooks, servicios o endpoints del flujo.
- Consulta `../modules/` cuando el cambio afecte arquitectura, infraestructura, datos, IA, seguridad, pruebas, Capacitor o despliegue.
- El codigo real, las migraciones y la configuracion siguen siendo la fuente principal de verdad.
