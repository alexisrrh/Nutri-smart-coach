# Funcionalidades

Este directorio documenta las funcionalidades actuales confirmadas en el código de NutriSmart Coach. Antes de modificar una funcionalidad, lee este índice, su documento específico y los módulos técnicos relacionados en `../modules/`.

## Índice

- `authentication.md`: sesión Supabase, rutas protegidas y consentimiento legal.
- `ai-food-analysis.md`: análisis IA de fotos/descripciones de comida.
- `diets.md`: generación de planes de dieta, progreso y reescritura premium.
- `meals.md`: historial, borrado y totales de comidas analizadas.
- `checkins.md`: check-ins corporales con imagen y análisis IA.
- `progress.md`: registros de peso, resumen de progreso y gamificación.
- `routines.md`: rutinas personalizadas, sesiones y compartición pública.
- `premium.md`: estado Premium, Stripe y verificación móvil.
- `referrals.md`: códigos de invitación y recompensas.
- `creators.md`: panel de creadores, solicitudes, enlaces y pagos.
- `profile-settings.md`: perfil, preferencias, tema, IA, legal y seguridad.

## Uso

- Consulta el documento de funcionalidad antes de tocar páginas, hooks, servicios o endpoints del flujo.
- Consulta `../modules/` cuando el cambio afecte arquitectura, infraestructura, datos, IA, seguridad, pruebas, Capacitor o despliegue.
- El código real, las migraciones y la configuración siguen siendo la fuente principal de verdad.
